Three clear steps

From full card to a clean handoff.

The everyday workflow stays simple. Deeper automation and delivery controls are there when a job needs them.

1

Import safely

Start from an SD card, external drive, folder, or FTP source. Check the exact plan before copying, then optionally verify the destination and create a second local copy.

  • Import Check before files move
  • Duplicate and destination-conflict handling
  • Optional checksum verification and backup destination
2

Find the best

Keptra groups bursts and similar frames so you can compare fewer decisions. Local analysis can surface sharpness, faces, people, and eye-region detail as review signals—not as permission to delete a photo.

  • Burst and near-duplicate grouping
  • Side-by-side Best-of review
  • Conservative suggestions with visible reasons
3

Review and hand off

Use familiar picks, rejects, stars, filters, and keyboard navigation. Queue only what should leave the card, then open the destination or export Lightroom helper files and an import manifest.

  • P to pick, X to reject, 1–5 to rate
  • Second-pass lane for uncertain frames
  • Import report, manifest, and Lightroom handoff helpers
